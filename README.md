## 🚀 Quick Start

### Local Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/Luminous-Dynamics/evolving-resonant-cocreationism.git
   cd evolving-resonant-cocreationism
   ```

2. **Serve locally**
   ```bash
   # Using Python
   python -m http.server 8000

   # Using Node.js
   npx serve .

   # Using PHP
   php -S localhost:8000
   ```

3. **Visit** `http://localhost:8000`

### Testing

```bash
# Install dependencies and Playwright browsers
npm run setup

# Run all tests (40+ tests across 6 browser/device configs)
npm test

# Run specific test suites
npm run test:accessibility   # WCAG 2.1 AA compliance tests
npm run test:core            # Core functionality tests
npm run test:performance     # Performance and optimization tests

# Interactive test modes
npm run test:ui              # Playwright test UI
npm run test:headed          # See tests run in browser
npm run test:debug           # Debug failing tests

# View test reports
npm run test:report
```
