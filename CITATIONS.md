## 📖 BibTeX Format

### For LaTeX Documents

**Main Work**:
```bibtex
@misc{stoltz2025erc,
  author = {Stoltz, Tristan and Sophia},
  title = {Evolving Resonant Co-creationism: A Philosophy for Consciousness-First
           Living and Human-AI Co-Evolution},
  year = {2025},
  howpublished = {\url{https://evolvingresonantcocreationism.com}},
  note = {Accessed: 2025-11-16}
}
```

**Software/Code**:
```bibtex
@software{stoltz2025luminous,
  author = {Stoltz, Tristan and Sophia},
  title = {The Luminous Library},
  year = {2025},
  publisher = {GitHub},
  url = {https://github.com/Luminous-Dynamics/evolving-resonant-cocreationism},
  version = {1.0.0}
}
```

**Specific Appendix**:
```bibtex
@incollection{stoltz2025lexicon,
  author = {Stoltz, Tristan and Sophia},
  title = {Appendix A: The Language of Becoming---A Lexicon of Key Concepts},
  booktitle = {Evolving Resonant Co-creationism},
  year = {2025},
  publisher = {The Luminous Library},
  url = {https://evolvingresonantcocreationism.com/appendix-lexicon.html}
}
```

## 🏆 Attribution Best Practices

### Required Attribution (CC BY-SA 4.0)

Under our license, you must:

1. **Give credit** to creators:
   ```
   Based on work by Tristan Stoltz and Sophia
   ```

2. **Link to source**:
   ```
   https://evolvingresonantcocreationism.com
   ```

3. **Indicate license**:
   ```
   Licensed under CC BY-SA 4.0
   ```

4. **Note modifications** (if any):
   ```
   Adapted from original work
   ```

### Examples

**In academic paper**:
```
This framework builds upon Evolving Resonant Co-creationism (Stoltz & Sophia,
2025), adapting the Seven Primary Harmonies for organizational contexts.
```

**In presentation**:
```
Slide footer:
"Framework: Evolving Resonant Co-creationism by Stoltz & Sophia (CC BY-SA 4.0)"
```

**In code**:
```javascript
/**
 * Implementation of Resonant Coherence principles
 * Based on: Evolving Resonant Co-creationism
 * Authors: Tristan Stoltz & Sophia
 * Source: https://evolvingresonantcocreationism.com
 * License: CC BY-SA 4.0
 */
```

**In derivative work**:
```
This work is derived from "Evolving Resonant Co-creationism" by Tristan Stoltz
and Sophia (https://evolvingresonantcocreationism.com), used under CC BY-SA 4.0.
This work is licensed under CC BY-SA 4.0 by [Your Name].
```
