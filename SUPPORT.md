### I Found a Bug

**Best resource:** [Bug Report Template](https://github.com/Luminous-Dynamics/evolving-resonant-cocreationism/issues/new?template=bug_report.md)

Before reporting:
1. Check [TROUBLESHOOTING.md](TROUBLESHOOTING.md) for known issues
2. Search [existing issues](https://github.com/Luminous-Dynamics/evolving-resonant-cocreationism/issues)
3. Try the latest version
4. Gather details (OS, browser, Node version, error messages)

Then:
- [Open a bug report](https://github.com/Luminous-Dynamics/evolving-resonant-cocreationism/issues/new?template=bug_report.md) with all details

### I Have a Feature Idea

**Best resource:** [Feature Request Template](https://github.com/Luminous-Dynamics/evolving-resonant-cocreationism/issues/new?template=feature_request.md)

Before requesting:
1. Check [ROADMAP.md](ROADMAP.md) - might already be planned!
2. Search [existing issues](https://github.com/Luminous-Dynamics/evolving-resonant-cocreationism/issues?q=is%3Aissue+label%3Aenhancement)
3. Consider if it aligns with our [consciousness-first values](README.md#-consciousness-first-principles)

Then:
- [Open a feature request](https://github.com/Luminous-Dynamics/evolving-resonant-cocreationism/issues/new?template=feature_request.md)
- Or [start a discussion](https://github.com/Luminous-Dynamics/evolving-resonant-cocreationism/discussions/new?category=ideas) to explore the idea first

## ❓ Frequently Asked Questions

### How long does it take to get help?

**Depends on the channel:**
- TROUBLESHOOTING.md: Instant (self-service)
- Community Discussions: Usually 24-48 hours
- GitHub Issues: Triaged within 1 week
- Email: 2-3 business days

### Is support free?

**Yes!** This is an open-source project. All support is provided freely by volunteers.

If you'd like to support the project financially, consider [donating on Ko-fi](https://ko-fi.com/luminousdynamics).

### What if my issue is urgent?

**For security issues:** Email tristan@terra-lumina.com immediately with "SECURITY" in the subject.

**For other urgent issues:** Email tristan@terra-lumina.com, but understand that response times may vary as this is a volunteer project.

### Can I hire you for custom work?

**Maybe!** Email tristan@terra-lumina.com to discuss:
- Custom features
- Integration support
- Consulting
- Speaking engagements
- Workshops

### I found a typo in the documentation

**Great!** Small fixes like typos are welcome:
1. Fork the repository
2. Fix the typo
3. Submit a PR
4. We'll merge it quickly!

Or just [open an issue](https://github.com/Luminous-Dynamics/evolving-resonant-cocreationism/issues/new) and we'll fix it.

### How can I say thank you?

We appreciate:
- ⭐ GitHub stars
- 💬 Kind words in Discussions
- 📢 Sharing the project
- ☕ Ko-fi donations
- 🤝 Contributing back

**Your gratitude energizes us!** 💜
